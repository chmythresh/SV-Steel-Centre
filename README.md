# SV-Steel-Centre

Digital Showroom & Commercial Distribution Portal for Sri Venkateswara Steel Centre (SV Steel Centre), Bhavanipuram, Vijayawada.

## 🏢 About SV Steel Centre
Established in 1989, Sri Venkateswara Steel Centre is a premier flat steel distribution dealership located in Bhavanipuram, Vijayawada, Andhra Pradesh. Specialising in prime Cold Rolled (CR) and Zinc / Galvanized Iron (GI) steel sheets sourced from integrated primary producers (Tata Steel, JSW Steel, Jindal Steel, and AM/NS India).

## 🚀 Key Features
- **Prime Mill Inventory Showcase:** Detailed product specifications for Cold Rolled (CRCA - IS 513) and Galvanized Iron (IS 277) steel sheets.
- **Precision Sheet Weight & Price Calculator:** Live calculation of single sheet weight, batch weight in KG and Metric Tonnes (MT) using Bureau of Indian Standards density constants (7,850 kg/m³ for CR, 7,870 kg/m³ for GI).
- **Dimension Conversion:** Real-time synchronization between Feet (ft) and Millimetres (mm) with standard industry presets (4×8 ft, 3×8 ft, 4×10 ft, 4×6.5 ft).
- **WhatsApp Instant Quotation Generator:** Generates pre-formatted RFQ messages and links directly to the Bhavanipuram sales desk.
- **Admin Management Portal:** Dedicated dashboard for monitoring ready stock tonnage, daily base rate updates, and weighbridge verification logs.

## 🛠️ Tech Stack
- **Framework:** React 19 + Vite 8
- **Styling:** Tailwind CSS v4 + Stitch Design System Tokens
- **Icons:** Material Symbols Outlined + Lucide React
- **Routing:** React Router v7
